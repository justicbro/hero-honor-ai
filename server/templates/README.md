# 模板目录

把要"看到就点"的按钮截图放在这里，命名规则：

- `tap_<name>.png` → 匹配到就 tap 中心点
- 其它前缀目前会被忽略（未来用于状态识别，如 `state_dead.png`）

## 怎么截模板

1. Mac 上 ADB 连上模拟器，进游戏到目标画面
2. `adb exec-out screencap -p > full.png`
3. 用任意图片工具裁出按钮区域，保存为 `tap_attack.png` 等
4. 把文件 scp 到服务器的本目录
5. 服务器重启即可加载

## 推荐第一个测试模板

`tap_confirm.png`：进入训练营后的"确认/开始"按钮 —— 触发频率高、误判代价低，适合验证链路。
